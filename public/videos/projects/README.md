# Видео для проектов

Добавьте сюда видео файлы ваших проектов для демонстрации на сайте.

## 📁 Структура файлов

```
public/videos/projects/
├── stellar-burgers.mp4
├── web-larek.mp4
└── mods-guide.mp4
```

## 🎬 Рекомендации по созданию видео

### Формат и качество

- **Формат:** MP4 (H.264) - лучшая совместимость
- **Разрешение:** 1920x1080 (Full HD) или 1280x720 (HD)
- **Соотношение сторон:** 16:9
- **FPS:** 30 или 60
- **Битрейт:** 2-5 Mbps (баланс качества и размера)

### Длительность и содержание

- **Длительность:** 10-30 секунд
- **Что показывать:**
  - Главную страницу проекта
  - Основной функционал (2-3 фичи)
  - Интерактивные элементы
  - Плавные переходы между секциями

### Размер файла

- **Целевой размер:** 1-3 МБ
- **Максимум:** 5 МБ
- Используйте сжатие для оптимизации

## 🛠️ Инструменты для создания

### Запись экрана

- **Windows:** OBS Studio, ShareX, Windows Game Bar (Win+G)
- **Mac:** QuickTime, OBS Studio
- **Онлайн:** Loom, Screencastify

### Конвертация и сжатие

- **HandBrake** - бесплатное сжатие видео
- **FFmpeg** - командная строка:
  ```bash
  ffmpeg -i input.mov -c:v libx264 -crf 23 -preset medium -vf scale=1920:1080 -an output.mp4
  ```
- **CloudConvert** - онлайн конвертация

### Редактирование

- **DaVinci Resolve** - бесплатный профессиональный редактор
- **Shotcut** - простой бесплатный редактор
- **Clipchamp** - онлайн редактор

## 🎨 Альтернативы видео

### GIF анимация

Если видео слишком большое, можно использовать GIF:

```
public/videos/projects/
├── stellar-burgers.gif
├── web-larek.gif
└── mods-guide.gif
```

**Плюсы GIF:**

- Не нужно менять код
- Автоматически воспроизводятся
- Работают везде

**Минусы GIF:**

- Больший размер файла (5-20 МБ)
- Худшее качество
- Ограниченная палитра цветов

### Статичные изображения

Просто замените `.mp4` на `.png` или `.jpg` в `src/data/projects.ts`

## 🔄 Как обновить путь к медиа

Откройте `src/data/projects.ts` и измените пути:

```typescript
// Для видео
media: "/videos/projects/stellar-burgers.mp4",

// Для GIF
media: "/videos/projects/stellar-burgers.gif",

// Для изображения
media: "/images/projects/stellar-burgers.png",
```

Тип медиа определяется автоматически по расширению файла!

## ✨ Советы

1. **Оптимизируйте видео** перед загрузкой - это ускорит загрузку сайта
2. **Используйте плавные переходы** в видео для профессионального вида
3. **Тестируйте на мобильных** - видео должны хорошо выглядеть везде
4. **Зацикливание автоматическое** - видео будет повторяться бесконечно
5. **Без звука** - видео воспроизводятся без звука (muted)
