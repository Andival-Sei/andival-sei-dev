# 🔍 Руководство по Verification кодам для SEO

> **Важно:** Эти шаги выполняются **ПОСЛЕ** деплоя сайта на Vercel

---

## Что такое Verification коды?

Verification коды - это специальные мета-теги, которые подтверждают владение сайтом для поисковых систем. Они дают доступ к инструментам аналитики и мониторинга SEO.

---

## 🌐 Google Search Console

### Зачем нужно?

- 📊 Статистика поиска (запросы, клики, позиции)
- 🔍 Мониторинг индексации страниц
- 🐛 Обнаружение проблем SEO
- 📈 Core Web Vitals метрики
- 🗺️ Управление sitemap

### Пошаговая инструкция:

#### 1. Регистрация и добавление сайта

```
1. Перейдите на https://search.google.com/search-console
2. Войдите через Google аккаунт
3. Нажмите "Добавить ресурс"
4. Выберите "URL-префикс"
5. Введите URL: https://andival-sei.vercel.app
```

#### 2. Получение verification кода

```
1. Выберите метод проверки: "HTML-тег"
2. Скопируйте код из тега:
   <meta name="google-site-verification" content="ABC123XYZ..." />
3. Вам нужен только код: ABC123XYZ...
```

#### 3. Добавление кода в проект

**Локально в `.env.local`:**

```env
NEXT_PUBLIC_GOOGLE_VERIFICATION=ABC123XYZ...
```

**На Vercel:**

```
1. Откройте проект на Vercel
2. Settings → Environment Variables
3. Добавьте:
   - Name: NEXT_PUBLIC_GOOGLE_VERIFICATION
   - Value: ABC123XYZ...
   - Environment: Production, Preview, Development
4. Сохраните
```

#### 4. Redeploy и проверка

```bash
# Локально коммит и пуш (если нужен новый деплой):
git add .
git commit -m "feat: добавить Google verification код"
git push

# Или просто redeploy на Vercel вручную
```

```
5. Подождите завершения деплоя
6. Вернитесь в Google Search Console
7. Нажмите "Подтвердить"
8. ✅ Готово! Теперь есть доступ к статистике
```

#### 5. Что делать после подтверждения

```
1. Отправьте sitemap:
   - Перейдите в "Индекс" → "Файлы Sitemap"
   - Добавьте URL: https://andival-sei.vercel.app/sitemap.xml

2. Подождите 2-3 дня для первых данных

3. Проверяйте регулярно:
   - Производительность (запросы и клики)
   - Покрытие (проиндексированные страницы)
   - Удобство использования (мобильная версия)
   - Core Web Vitals
```

## 🟦 Яндекс.Вебмастер

### Зачем нужно?

- 📊 Статистика для рунета
- 🔍 Индексация в Яндексе
- 📈 Мониторинг позиций

### Пошаговая инструкция:

#### 1. Регистрация

```
1. Перейдите на https://webmaster.yandex.ru
2. Войдите через Яндекс аккаунт
3. Добавьте сайт: https://andival-sei.vercel.app
```

#### 2. Получение кода

```
1. Выберите метод: "Meta-тег"
2. Скопируйте код (обычно вида: 1234567890abcdef)
```

#### 3. Добавление в проект

**Локально в `.env.local`:**

```env
NEXT_PUBLIC_YANDEX_VERIFICATION=1234567890abcdef
```

**На Vercel:**

```
Добавьте в Environment Variables:
NEXT_PUBLIC_YANDEX_VERIFICATION=1234567890abcdef
```

#### 4. Подтверждение

```
1. Redeploy на Vercel
2. Вернитесь в Яндекс.Вебмастер
3. Нажмите "Проверить"
4. ✅ Готово!
```

## ❓ Часто задаваемые вопросы

### Обязательно ли это делать?

**Нет!** Это опционально:

- ✅ Делайте если хотите мониторить SEO
- ❌ Можно пропустить для личного портфолио

### Когда делать?

**После деплоя на Vercel:**

1. Сначала задеплойте сайт
2. Убедитесь что всё работает
3. Потом добавляйте verification

### Сколько времени займет?

- Google Search Console: ~5 минут
- Яндекс.Вебмастер: ~5 минут
- Ожидание данных: 2-7 дней

### Что если не добавить коды?

Ничего страшного:

- ✅ SEO будет работать
- ✅ Google найдет сайт через sitemap
- ❌ Не будет доступа к статистике
