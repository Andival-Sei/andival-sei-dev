## 🛠️ Инструменты и зависимости

### Новые зависимости

```bash
# CI/CD и качество кода
pnpm add -D husky lint-staged @commitlint/cli @commitlint/config-conventional
pnpm add -D @playwright/test

# SEO и производительность
pnpm add next-intl @vercel/analytics
pnpm add -D @next/bundle-analyzer

# Мониторинг
pnpm add @sentry/nextjs

# Формы
pnpm add resend react-hook-form @hookform/resolvers zod
```

### Конфигурационные файлы

- `.github/workflows/ci.yml` - GitHub Actions
- `.husky/` - Git hooks
- `playwright.config.ts` - E2E тесты
- `commitlint.config.js` - Commit linting
- `sentry.client.config.ts` - Error tracking
